WhoScored table exporter

Drag this button to your browser's bookmarks bar:

Export WhoScored player tables

  1. Open an accessible WhoScored domestic-league player-statistics page.
  2. Select 2026/2027 and open the league's Player Statistics page.
  3. Click the saved bookmark. It uses the Detailed view's Total option and downloads the source data with verified pagination.
  4. Convert the downloaded capture using scrape_whoscored_stats.py --from-capture /path/to/capture.json.

The exporter reads the current page and clicks its table controls. It sends no data to another service. It stops on blocked access, unknown units, ambiguous tables or incomplete pagination. The exact reporting cutoff must be verified before values can be attached to your November 2 dataset.

If the site blocks the bookmark or the layout has changed, retain its error and do not treat a partial capture as a complete export.
